# 🌌 Universo Desconhecido

O **Universo Desconhecido** é uma interface criada com **HTML, CSS e JavaScript**, com o objetivo de apresentar informações sobre o espaço de forma simples e interativa.

## 🚀 Sobre o projeto

O site possui:

* 🏠 Página inicial
* 🪐 Informações sobre os planetas do Sistema Solar
* 🔭 Curiosidades sobre o espaço
* 🎲 Botão para descobrir um planeta aleatoriamente
* 📱 Interface adaptada para diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura do site
* **CSS3** — aparência e organização visual
* **JavaScript** — interatividade

## 📂 Estrutura do projeto

```text
Universo-Desconhecido/
│
├── index.html
├── style.css
└── script.js
```

## 🎯 Objetivo

Este projeto foi desenvolvido para praticar conceitos de **HTML, CSS e JavaScript**, criando uma interface sobre astronomia e exploração espacial.

## 🌌 Tema

O projeto utiliza um visual inspirado no espaço, com **tons escuros, azul profundo e elementos relacionados ao universo**.
